<h3 id="project1">Project 1: AI Venture & Company Research System</h3>
<p>
  An AI-powered research system that takes a startup idea or company name as input and automatically
  researches market size, competitors, funding history, financial health, and risks. It uses automated
  planning, parallel web retrieval, and self-verification to produce a structured, cited research report —
  reducing what would normally be hours of manual market research into a single automated pipeline.
</p>

<h4>Technologies Used</h4>
<ul>
  <li><strong>Frontend:</strong> Next.js, TypeScript, Tailwind CSS, shadcn/ui</li>
  <li><strong>Backend:</strong> FastAPI, LangGraph (agentic orchestration)</li>
  <li><strong>Database:</strong> PostgreSQL with pgvector, via Supabase</li>
  <li><strong>LLMs:</strong> Groq (primary), Gemini (secondary — verification & embeddings)</li>
  <li><strong>Web Retrieval:</strong> Tavily</li>
  <li><strong>Deployment (planned):</strong> Vercel (frontend), Render/Fly.io free-tier (backend)</li>
</ul>

<h4>Roles and Responsibilities</h4>
<ul>
  <li>Designed and built the end-to-end backend architecture (FastAPI + LangGraph agentic pipeline)</li>
  <li>Implemented SQLAlchemy models and Alembic migrations for the research-report data model</li>
  <li>Built exact-string query caching to minimize Gemini API usage and reduce redundant calls</li>
  <li>Fixed schema, persistence, and rate-limiting issues found during code review</li>
  <li>Owned the project independently as the solo developer, from architecture to implementation</li>
</ul>
